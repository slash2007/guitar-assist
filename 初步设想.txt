**「吉他指板可视化 + 间隔重复记忆系统」详细方案**

### 一、产品定位
一款帮助吉他学习者**高效记住指板上所有音符、音阶、和弦、琶音位置**的工具型网站。  
核心解决痛点：  
- 传统死记硬背效率低、容易忘  
- 现有指板图大多是静态的，缺乏科学复习机制  
- 学了很多形状，但实际弹奏时反应不过来

目标用户：  
- 初级到中级吉他手（会按和弦，但指板不熟）  
- 想系统提升即兴、视奏、编曲能力的进阶学习者

### 二、核心功能模块

#### 1. 交互式指板可视化（基础层）
- **多视角指板**：支持标准调弦、Drop D、Open调等，可切换左手/右手视角
- **高亮显示**：
  - 单音高亮（点击任意品格显示音名、音程关系）
  - 音阶高亮（自然大调、自然小调、五声音阶、布鲁斯、教会调式等）
  - 和弦高亮（三和弦、七和弦、挂留和弦等，支持所有把位）
  - 琶音高亮
- **动态演示**：可播放音阶/和弦的上行下行，指板同步高亮 + 真实吉他音色
- **自定义显示**：显示/隐藏音名、品位数字、弦名、音程标记
- **多种指板样式**：深色/浅色、木质纹理、极简模式

#### 2. 间隔重复记忆系统（核心竞争力）
采用类似 Anki 的间隔重复算法（SM-2 改进版），专门针对吉他指板设计。

**学习内容类型**：
- 单音位置记忆（最基础）
- 音阶形状记忆（CAGED 系统 + 3NPS 等）
- 和弦形状与功能记忆
- 音程关系快速反应
- 任意调式的快速定位

**练习模式**：
1. **识别模式**：指板高亮一个位置，用户选择正确音名/音程/所属音阶
2. **定位模式**：给出音名或音阶名称，用户在指板上点击正确位置
3. **听音定位**：播放声音，用户在指板上找到对应位置
4. **限时挑战**：在规定时间内完成尽量多的正确识别

**复习机制**：
- 根据用户回答正确率和反应速度，自动计算下次复习时间
- 支持「再次、困难、良好、简单」四档反馈
- 每日推荐复习卡片数量可自定义
- 薄弱环节自动加强（例如某根弦的某几个音总是错）

#### 3. 学习路径与进度系统
- **预设学习路径**：
  - 新手路径：先掌握 CAGED 五个区域的基本和弦与音阶
  - 五声音阶精通路径
  - 全指板音符精通路径
  - 调式与进阶音阶路径
- **自定义学习集**：用户可自己创建「我要攻克的音阶/和弦」集合
- **数据看板**：
  - 总掌握音符数量 / 音阶数量
  - 各弦、各把位熟练度热力图
  - 每日/每周学习时长与正确率趋势
  - 预估完全掌握全指板所需时间

#### 4. 辅助功能
- 节拍器集成（练习时同步）
- 真实吉他音色切换（电吉他/木吉他/古典）
- 移动端适配（手机上也能高效刷卡）
- 练习提醒（浏览器通知 / 邮件）
- 导出学习报告（方便分享或给老师看）

### 三、用户核心使用流程（典型路径）

1. **首次进入** → 简单水平测试（识别几个音、弹几个音阶）→ 生成初始学习计划  
2. **每日练习** → 打开「今日复习」→ 系统推送到期卡片 → 完成识别/定位练习 → 反馈难度 → 进入新内容学习  
3. **自由探索** → 在指板模式下随意点选音阶/和弦，配合声音加深印象  
4. **阶段性检验** → 系统定期发起「全指板抽查测试」，更新掌握度数据  

### 四、MVP 版本建议（最小可行产品）

**第一阶段只做以下功能，尽快上线验证：**
- 标准调弦交互指板（支持音阶与基础和弦高亮）
- 单音位置记忆的间隔重复系统（识别 + 定位两种模式）
- 简单的学习进度统计
- 用户账号与云端同步
- 基础音色播放

**暂不做**：
- 复杂调式
- 听音定位
- 高度自定义学习路径
- 社区功能

### 五、技术实现要点（简要）

- 前端：React / Vue + Canvas 或 SVG 绘制指板（性能更好）
- 音频：Web Audio API 或预录音色
- 间隔重复算法：可直接使用已有开源实现（如 ts-fsrs 或自己实现 SM-2）
- 后端：用户数据、卡片状态、学习记录存储
- 移动端：响应式设计优先，后期可考虑 PWA

### 六、差异化与竞争力

| 对比点       | 普通指板网站     | 本产品                  |
|--------------|------------------|-------------------------|
| 指板展示     | 静态图片为主     | 高度交互 + 声音同步     |
| 记忆方法     | 无               | 科学间隔重复            |
| 个性化       | 弱               | 根据正确率和反应速度调整|
| 数据反馈     | 几乎没有         | 热力图 + 掌握度预测     |
| 学习闭环     | 看完就走         | 每日复习 + 持续追踪     |

### 七、变现模式建议
- **免费版**：每日有限复习卡片 + 基础音阶
- **Pro 订阅**（核心收入）：无限卡片、全部音阶/和弦、详细数据分析、自定义学习集、听音模式
- 后续可增加：老师/琴行团队版（查看学生进度）
